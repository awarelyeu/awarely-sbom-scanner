# Optional Syft import and Java assessment

Import selected CycloneDX JSON application inventories from Syft or another compatible producer. Keep native Linux/npm/Python collection, export locally, check through the API or synchronize a scoped source. Syft remains separately installed and optional; it is never automatically executed or downloaded.

Java assessment retains Maven coordinates and version ordering. NuGet, Go, Composer, RubyGems and Cargo support inventory/sync with explicit unevaluated CVE coverage. Import validates bounded input, removes arbitrary metadata, deduplicates identities and refuses to sync partial snapshots.

See [English guide](https://github.com/awarelyeu/awarely-sbom-scanner/blob/v0.6.0-alpha.1/docs/how-to.md#syft) and [Romanian guide](https://github.com/awarelyeu/awarely-sbom-scanner/blob/v0.6.0-alpha.1/docs/how-to.ro.md#syft). This remains a prerelease; Jenkins is a later stage.
